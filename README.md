# FindMI E-Commerce

---

## 🚀 How to Run the Project

### 1. Install Dependencies

```bash
bun install
```

### 2. Start the Development Server

```bash
bun run dev
```

The app will be available at [http://localhost:4242](http://localhost:4242) by default.

To add any components of ShadCN:

```bash
bunx --bun shadcn@latest add component-name
```

### 3. Build for Production

```bash
bun run build
```

The production-ready files will be in the `dist` folder.

### 4. Preview the Production Build

```bash
bun run preview
```

---

## Additional Notes

- Make sure you have [Bun](https://bun.sh/) installed.
- Tailwind CSS and ESLint are pre-configured.
- For Docker usage, see the `Dockerfile` and `docker-compose.yml` in this directory.
